具體要修的話，這個 SQL 需要變成 parameterized view 或者 macro，讓 `label_date` 作為輸入參數，然後兩邊都加 `where` 條件：`affinity_base` 加 `where day_start < label_date`，`monetization_affinity` 加 `where event_time < label_date`。不是「預留」，是必須強制。

Jason，這些 drafts 是準備上 production 的還是純粹探索階段？如果要用在 ranking model，光靠註解提醒是擋不住 leakage 的——需要在 SQL 層面硬卡。
