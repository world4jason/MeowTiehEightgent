# Remove hermes-paperclip-adapter Implementation Plan

> **For agentic workers:** Execute this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. Each task ends with an atomic commit. Read each file before editing to confirm line numbers match — they may drift if earlier tasks shift lines.

**Goal:** Cleanly remove the `hermes-paperclip-adapter` npm dependency and all `hermes_local` adapter references from the codebase.

**Architecture:** The `hermes-paperclip-adapter` (v0.1.1) is an external npm package that implements the `ServerAdapterModule` interface as type `"hermes_local"`. It is referenced in 5 source files + `server/package.json` + `pnpm-lock.yaml`. The UI never exposed `hermes_local` in any dropdown (NewAgentDialog, OnboardingWizard, AgentProperties) — it only appeared in the `isLocal` guard in AgentDetail and the `AGENT_ADAPTER_TYPES` constant. Removal is purely deletive — no replacement adapter is created. No database migrations reference hermes.

**Tech Stack:** TypeScript, React (UI), pnpm workspace monorepo

---

## Context for the executing session

This is a pnpm workspace monorepo. Key paths:

```
server/                          # Express backend
  src/adapters/registry.ts       # Adapter registry — imports all adapters, builds a Map
  src/adapters/types.ts          # Re-exports from @meowtieheightgent/adapter-utils
  package.json                   # Has the hermes-paperclip-adapter dependency
packages/shared/src/constants.ts # Shared constants (AGENT_ADAPTER_TYPES enum)
ui/
  packages/shared/src/constants.ts  # Duplicate shared constants for UI build
  src/pages/AgentDetail.tsx         # Agent detail page, has isLocal check
```

The `ServerAdapterModule` interface requires: `type`, `execute()`, `testEnvironment()`, and optional `sessionCodec`, `models`, `supportsLocalAgentJwt`, `agentConfigurationDoc`, etc.

Each adapter is registered in `registry.ts` via a `Map<string, ServerAdapterModule>`. The hermes adapter is one entry in that map.
