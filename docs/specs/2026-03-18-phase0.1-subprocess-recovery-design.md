## 問題描述

目前 `stream_cli_agent()` 和 `call_cli_agent()` 完全沒有容錯機制：

| 失效模式 | 目前行為 |
|---------|---------|
| 指令找不到（command not found）| `FileNotFoundError` 往上傳播，可能卡死整輪 |
| Process crash（非 0 exit code）| 拿到空輸出，無錯誤提示 |
| Process 完全無回應（hang）| 永久 block，WS 沒有回應 |
| Streaming 中途 crash | 已輸出的 chunk 全部丟失 |

---

## 設計目標

1. **不卡死**：任何 agent 失敗都不影響同一輪其他 agent
2. **保留 partial output**：已收到的 chunk 不丟棄，標記 `[TRUNCATED]`
3. **補完輪**：被截斷的 agent 在下一次輪到他時，自然補完想法
4. **使用者可見的錯誤**：前端顯示錯誤 badge，不是沉默失敗

---

## Timeout 策略

使用 **Idle Timeout**（不是 Total Timeout）：

- **Idle timeout**：每次 `read()` 呼叫超過 N 秒沒有新 chunk → 截斷。適合 claude 這種合法思考很久的 agent——「完全沒動靜」才是問題。
- **Startup timeout**：`create_subprocess_exec` 成功後，第一個 byte 超過 N 秒沒來 → startup failed

**已知限制（接受）：** 若 subprocess 以非常慢但非零的速度持續輸出（如每 70 秒一個 byte），兩個 timeout 都不觸發。此情境視為合法慢速輸出，Phase 0.1 不處理。

**預設值：**
- `idle_timeout_seconds`: 60
- `startup_timeout_seconds`: 10

**Config 優先序（高 → 低）：**
1. `agents/<name>/config.json` 的 `idle_timeout_seconds`
2. `config.json` 的 model 層（如 `claude.idle_timeout_seconds`）
3. 程式碼 fallback 預設值（60s / 10s）

## Exception 類別

```python
class SubprocessError(Exception):
    """所有 subprocess 失敗的 base class"""
    def __init__(self, agent: str, partial_output: str = "", stderr_output: str = ""):
        self.agent = agent
        self.partial_output = partial_output   # 可以是空字串
        self.stderr_output = stderr_output

class SubprocessStartupError(SubprocessError):
    """指令找不到、permission denied、或啟動後 startup_timeout 內無輸出"""
    pass

class SubprocessTimeoutError(SubprocessError):
    """Idle timeout：N 秒無新 chunk"""
    def __init__(self, agent, partial_output, stderr_output, timeout_seconds):
        super().__init__(agent, partial_output, stderr_output)
        self.timeout_seconds = timeout_seconds

class SubprocessCrashError(SubprocessError):
    """Process 以非 0 exit code 結束，或 mid-stream 發生 exception"""
    def __init__(self, agent, partial_output, stderr_output, exit_code=None, cause=""):
        super().__init__(agent, partial_output, stderr_output)
        self.exit_code = exit_code
        self.cause = cause
```

## `stream_cli_agent()` 改造（app.py:511）

**Read loop 結構：** `asyncio.wait_for` 包住**每次個別的 `read()` 呼叫**。EOF 自然由 `read()` 回傳 `b""` 偵測，與 timeout 不衝突。

**Stderr：** 改為 `asyncio.subprocess.PIPE` 捕捉，不加入 `partial_output`，只放進 `stderr_output` 供 error event 使用。

```python
async def stream_cli_agent(agent: dict, prompt: str, images=None):
    idle_timeout = _resolve_timeout(agent, "idle_timeout_seconds", 60)
    startup_timeout = _resolve_timeout(agent, "startup_timeout_seconds", 10)
    buffer = ""

    # 捕捉 command not found / permission denied
    try:
        proc = await asyncio.create_subprocess_exec(
            *agent["cmd"], *extra_args, prompt,
            stdout=asyncio.subprocess.PIPE,
            stderr=asyncio.subprocess.PIPE,   # 改為 PIPE
            cwd=agent["workspace"],
        )
    except (FileNotFoundError, PermissionError, OSError) as e:
        raise SubprocessStartupError(agent=agent["name"], cause=str(e))

    stderr_task = asyncio.create_task(proc.stderr.read())

    try:
        # Startup timeout：等第一個 byte
        try:
            first_chunk = await asyncio.wait_for(
                proc.stdout.read(256), timeout=startup_timeout
            )
        except asyncio.TimeoutError:
            proc.kill()
            await proc.wait()
            raise SubprocessStartupError(
                agent=agent["name"],
                cause=f"no output within {startup_timeout}s"
            )

        if not first_chunk:
            # EOF immediately
            raise SubprocessCrashError(agent=agent["name"], cause="empty output")

        decoded = first_chunk.decode(errors='replace')
        buffer += decoded
        yield decoded

        # Idle timeout：後續每個 chunk
        while True:
            try:
                chunk = await asyncio.wait_for(
                    proc.stdout.read(256), timeout=idle_timeout
                )
            except asyncio.TimeoutError:
                proc.kill()
                await proc.wait()
                stderr_out = await stderr_task
                raise SubprocessTimeoutError(
                    agent=agent["name"],
                    partial_output=buffer,
                    stderr_output=stderr_out.decode(errors='replace'),
                    timeout_seconds=idle_timeout,
                )
            if not chunk:   # EOF，正常結束
                break
            decoded = chunk.decode(errors='replace')
            buffer += decoded
            yield decoded

    except SubprocessError:
        raise   # 已是我們的類型，直接往上

    except Exception as e:
        proc.kill()
        await proc.wait()
        stderr_out = await stderr_task
        raise SubprocessCrashError(
            agent=agent["name"],
            partial_output=buffer,
            stderr_output=stderr_out.decode(errors='replace'),
            cause=str(e),
        )

    # 正常結束：檢查 exit code
    await proc.wait()
    stderr_out = await stderr_task
    if proc.returncode != 0:
        raise SubprocessCrashError(
            agent=agent["name"],
            partial_output=buffer,
            stderr_output=stderr_out.decode(errors='replace'),
            exit_code=proc.returncode,
        )
```

## WebSocket Handler（app.py:~1500）

**「繼續下一個 agent」的語意：** 指**同一輪剩餘的 agent 繼續執行**。被截斷的 agent 在下一輪（round-robin 回來時）才補完。

**`[TRUNCATED]` 在 history 中的位置：** 作為該 agent 訊息的 suffix，附在 partial_output 後面。

```python
accumulated = ""
had_error = False

try:
    async for chunk in stream_cli_agent(agent, prompt, images):
        accumulated += chunk
        await ws.send_json({"type": "chunk", "agent": agent["name"], "text": chunk})

    response = accumulated

except SubprocessError as e:
    had_error = True
    response = e.partial_output + (" [TRUNCATED]" if e.partial_output else "")

    # agent_error 事件：不重複傳 partial_text（已作為 chunk 送出）
    # 只傳 error metadata，前端在已渲染的內容上加 badge
    await ws.send_json({
        "type": "agent_error",
        "agent": agent["name"],
        "error_type": type(e).__name__,
        "message": _error_message(e),
        # partial_text 只在 SubprocessStartupError 時傳（因為沒有 chunk 被送出）
        "partial_text": e.partial_output if isinstance(e, SubprocessStartupError) else None,
    })

    # 標記補完輪
    agent["pending_continuation"] = True

# 無論成功或失敗，response 都進 history（讓後續 agent 看到截斷）
history_text += f"\n[{agent['name']}]: {response}\n"
# 繼續同輪下一個 agent（不 break）
```

## `build_prompt()` 補完輪（app.py:362）

```python
def build_prompt(agent, history_text, workspace_id=None, all_agents=None):
    # ... 現有邏輯不變 ...

    continuation_hint = ""
    if agent.get("pending_continuation"):
        continuation_hint = (
            "\n\n[系統提示] 你在上一輪說到一半被打斷了"
            "（歷史中可看到 [TRUNCATED] 標記）。"
            "這輪你可以選擇繼續完整你的想法，或先回應其他人的發言再補充。"
        )
        agent["pending_continuation"] = False  # 清掉 flag（無論這輪是否成功）

    return (
        f"{context}\n\n===== DISCUSSION =====\n\n"
        f"{participants_header}\n{history_text}"
        f"{continuation_hint}\n\n"
        "Your turn. Respond as your persona dictates."
    )
```

**Flag 生命週期：**
- 設定：WS handler 捕捉到 `SubprocessError` 時
- 清除：`build_prompt()` 呼叫時（不等下一輪是否成功）
- Session 結束時自然消失（in-memory）
- 若連續多輪都失敗：flag 設→清→設，補完 hint 只在「第一個成功說話的輪次」出現。此行為符合預期（Phase 0.1 不限制補完次數，接受此 tradeoff）

## WebSocket 事件：`"agent_error"`

```json
{
  "type": "agent_error",
  "agent": "claude",
  "error_type": "SubprocessTimeoutError | SubprocessCrashError | SubprocessStartupError",
  "message": "Agent claude timed out after 60s of inactivity",
  "partial_text": null
}
```

**`partial_text` 規則：**
- `SubprocessStartupError`：傳 `partial_text`（因為沒有 chunk 被送出，frontend 需要內容）
- `SubprocessTimeoutError` / `SubprocessCrashError`：`partial_text = null`（chunk 已逐一送出，不重複）

## 測試計畫（TDD）

### Unit Tests（mock subprocess）

| 測試 | mock 方式 | 預期 |
|------|----------|------|
| Startup timeout | `proc.stdout.read()` 永不返回 | raise `SubprocessStartupError` |
| Idle timeout mid-stream | 輸出 3 chunks 後 read() hang | raise `SubprocessTimeoutError`，`partial_output` 有內容 |
| Process crash (exit 1) | `proc.returncode = 1` | raise `SubprocessCrashError` |
| Command not found | mock `create_subprocess_exec` raise `FileNotFoundError` | raise `SubprocessStartupError` |
| Empty output (startup ok but EOF immediately) | `read()` 返回 `b""` | raise `SubprocessCrashError` |
| Stderr captured | subprocess 輸出到 stderr | `e.stderr_output` 非空 |
| Normal success | 正常輸出後 EOF + exit 0 | 不 raise，yield 所有 chunks |

### Integration Tests（WS handler）

| 測試 | 情境 | 預期 |
|------|------|------|
| Skip agent, others continue | agent A timeout，A 後有 agent B | WS 收到 A 的 `agent_error` + B 的正常 chunks |
| History contains TRUNCATED | agent crash mid-stream | `history_text` 含 `[Claude]: partial [TRUNCATED]` |
| `agent_error` event for startup failure | command not found | WS 收到 `{type: "agent_error", partial_text: null}` 或含 partial |
| `partial_text` null when chunks sent | timeout after chunks | `agent_error.partial_text == null` |
| `partial_text` present when startup fails | startup timeout | `agent_error.partial_text` 為空字串（無內容可傳）|

### Continuation Prompt Tests

| 測試 | 情境 | 預期 |
|------|------|------|
| Continuation hint injected | `agent["pending_continuation"] = True` 時呼叫 `build_prompt` | prompt 含「說到一半被打斷」 |
| Flag cleared after build_prompt | 同上 | `agent["pending_continuation"] == False` |
| No hint when flag false | 正常 agent | prompt 不含補完 hint |
| Flag reset on consecutive fails | 連續兩輪都 fail | 第二次失敗時 flag 重設為 True，下次 build_prompt 仍有 hint |
