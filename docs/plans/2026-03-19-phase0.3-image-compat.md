# Phase 0.3 Image Compatibility Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan.

**Goal:** Prevent `SubprocessCrashError` when images are sent to agents that don't support `--add-file` (e.g. codex) by adding a `supports_image` capability flag per model/agent and guarding image injection before `write_temp_images()`.

**Architecture:** Add `supports_image` bool to `DEFAULT_MODELS`, add `_resolve_supports_image()` helper with agent > model_config > DEFAULT_MODELS > True precedence, guard `write_temp_images()` call in `stream_cli_agent()`.

**Tech Stack:** Python 3.11+, pytest

**Spec:** `docs/specs/2026-03-19-phase0.3-image-compat-design.md`

```python
def _resolve_supports_image(agent: dict) -> bool:
    """Precedence: agent-level > model_config > DEFAULT_MODELS > True (safe default)."""
    if "supports_image" in agent:
        return bool(agent["supports_image"])
    model_cfg = agent.get("model_config") or {}
    if "supports_image" in model_cfg:
        return bool(model_cfg["supports_image"])
    model_name = agent.get("model", "")
    if model_name in DEFAULT_MODELS and "supports_image" in DEFAULT_MODELS[model_name]:
        return bool(DEFAULT_MODELS[model_name]["supports_image"])
    return True
```
