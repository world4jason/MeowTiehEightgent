### Feature 1: Think Mode — model_tiers

- **resolve_thinking_model()** — runtime model resolution from `model_tiers` dict
- **stream_agent()** — dispatches to thinking model's cmd when think mode active, separates `subprocess_mode` from `_current_mode` (badge vs CLI flag)
- **build_mode_switch_notification()** — WS system message 通知 model 切換
- **_handle_set_mode()** — extracted shared WS handler (DRY, was 3 identical blocks)
- **agents/gemini/config.json** — `supports_thinking: true`, `model_tiers: { thinking: "gemini-2.5-pro" }`
- **config.json** — added `gemini-2.5-pro` model entry
- **Settings UI** — AgentsTab: 「支援思考模式」checkbox + thinking model dropdown

### Feature 2: History Summarization Phase 2

- **history_manager.py** — NEW module, extracted from app.py (~200 LOC reduction)
  - `compress_history()` — core summarization with summary.json cache, failure cooldown (5 min), threshold gating
  - `load_session_config()` — per-session config override
  - `_format_history_text()` — DRY history formatting helper
  - `SUMMARIZATION_PROMPT` — LLM self-determines conversation type (task vs casual)
  - `truncate_history()`, `apply_sliding_window()` — moved from app.py
- **WS loop integration** — compress_history called at resume + per-turn, with on_progress callback
- **summary.json cache** — `covered_message_count`, `total_message_count`, failure marker, cooldown
- **Per-session config** — `history/{session_id}/session_config.json` overrides global
