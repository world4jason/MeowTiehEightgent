## 今日工作摘要

### 1. MassGen 競品研究

讀了兩份由外部 LLM 產出的 MassGen 深度分析報告：
- Gemini Deep Research 產出的架構與背景報告
- PDF 技術報告（另一 LLM 整理）涵蓋工程細節

**MassGen 核心機制整理：**
- Orchestrator / Agent / Backend 三層架構
- 並行多 LLM + 投票共識（所有 agent 完成投票後票數最高者獲勝）
- Inject-and-Continue：agent A 輸出後立即注入其他 agent context，不等整輪結束
- Substantive Gate：把 answer 變動分 Structural / Transformative / Incremental，防止增量漂移
- Changedoc：agent 輸出含 `[RATIONALE]` 區塊，注入其他 agent context，公式 W_final = f(A_content, D_rationale, V_consensus)
- status.json：automation mode 每 2 秒更新，含 phase / agents / vote_distribution
- Fairness Gate：防止速度快的小 model 主導討論
- Protected Paths：workspace 寫入白名單
- Vector Memory MCP：跨 session 向量記憶
- 多層 Model 路由：簡單任務 → 便宜 model，核心推理 → 高性能 model
- ContextCompressor：自動漸進式壓縮過長 context
