## Process — 今天走完的 Pipeline

### Office Hours — "Agent as Human" Thesis

Brainstorming 用 3-model review（Codex GPT-5.4 + Claude Sonnet + Claude Haiku）。

**用戶原話：** 「Chat 跟 Cowork 不能互通，這產品就不完整。希望 agent as human 的感覺。」

**3 個真實使用痛點：**
1. 沒有暫停控制 — 想 pause 時 agent 繼續講
2. 多 topic 無法聚焦 — 1~N 議題混在一起（→ Room Goal）
3. 缺共享 artifact — 沒有白板（→ 未來參考 MassGen / Gather Town）

**Codex second opinion：** 48hr prototype 先做 Pause + 一個跨界 action（issue creation）。Claude 同意。

## 實戰 Gotchas（下次必讀）

1. **Pause 必須同步處理。** 不能放進 eventQueue 等 main loop drain。`ws.on("message")` callback 裡直接 `controller.abort()`。

2. **AbortSignal kill process 後不是立即結束。** `readWithTimeout()` 要等 stdout EOF（proc.kill → stdout `end` → resolve null）。

3. **Event bus 要 session-scoped。** 全域 singleton + 事件帶 sessionId + listener 端過濾。

4. **`ConversationEngine.onMention()` 是 Resume 的關鍵。** 不能只設 status，要推回 engine queue。

5. **Cowork issue status 是 `"done" | "cancelled"`。** 不是 `"closed"`。

6. **`loadSessionConfig` / `saveSessionConfig` 已存在於 `routes/sessions.ts`。** Export 就好，不要重寫。

7. **`BuildPromptOptions` 需要先加 `sessionId`。** TDD 順序：先改 interface → 寫 test → 再實作。
