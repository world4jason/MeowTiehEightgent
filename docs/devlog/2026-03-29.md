### 2. Pre-Compaction Memory Flush（v0.11.0 核心功能）

**三層記憶架構：**
- Layer 1: Working Memory — session history + kanban（即時）
- Layer 2: Session Memory — summary.json（壓縮後）
- Layer 3: Long-Term Memory — facts + entities（跨 session）

**雙時機觸發：**
- Pre-compaction（壓縮前）— regex heuristic，零 LLM 成本，< 10ms
- Post-session（session 結束後）— LLM 3-stage distillation，背景執行

**Distillation Pipeline：**（借鏡 OpenClaw Memory Stack 0.5.7 `distill.sh`）
1. Triage — LLM 評分 1-10，低分跳過（heuristic fallback）
2. Fact Extraction — LLM 抽取 8 種 fact 類型，importance ≥ 4 過濾
3. Entity Extraction — LLM 抽取 {entity: description}，JSON merge
4. Store — 寫入 `memory/YYYY-MM-DD.md` + `entities.json`

**防禦機制：**
- Semaphore(3) — 最多 3 個同時 distillation
- Timeout(60s) — 防 LLM hang
- Session dedup — 同 session 不重複蒸餾
- 全路徑 try/except — 失敗靜默降級
- Structured logging — triage score, facts count, duration

### 3. Memory Injection

`build_prompt()` 新增注入：
- `## Recent Memory` — importance-weighted facts，500 char budget，read-time dedup
- `## Known Entities` — entities.json，300 char budget

### 4. append_memory 路徑分離

原本 `append_memory()` 寫入 `memory/YYYY-MM-DD.md` 改為 `memory/raw/YYYY-MM-DD.md`，避免 raw dump 跟結構化 facts 混在一起。

## 刻意不做的（記錄為未來考量）

以下機制在調研中發現但**刻意不在 v0.11.0 實作**，原因與未來考量如下：

### Retrieval / Search 引擎

| 機制 | 來源 | 不做原因 | 未來考量 |
|------|------|---------|---------|
| BM25 全文搜索 | OpenClaw Memory Stack E1 | 需要 SQLite FTS5 依賴，目前 Markdown grep 夠用 | 記憶量大到 grep 太慢時加入 |
| 向量語義搜索 | OpenClaw E2 / mem0 | 需要 embedding model + 向量 DB（chromadb/faiss），成本和延遲未驗證 | Phase 4，先評估 embedding 成本 |
| DAG 壓縮歷史 | OpenClaw E3 | 複雜度太高，效益不明確 | 可能永遠不需要 |
| RRF Rank Fusion | OpenClaw | 沒有多引擎就不需要 fusion | 有多引擎時一起加 |
| PageRank 知識圖譜 | OpenClaw 概念 | 過度工程 | 實體關係複雜到一定程度再考慮 |

### Token 控制

| 機制 | 來源 | 不做原因 | 未來考量 |
|------|------|---------|---------|
| L0/L1/L2 tiered sidecar | OpenClaw `tiered-loading.sh` | 目前用 budget 限制（500+300 chars）夠用 | 記憶量大時，L0 摘要可以大幅省 token |
| Auto-expand（L0→L1→L2） | OpenClaw | 沒有 tiered 就不需要 expand | 一起加 |

### 其他

| 機制 | 來源 | 不做原因 | 未來考量 |
|------|------|---------|---------|
| Cross-agent memory sharing | OpenClaw CLI API + Drop zone | Meow agent 共用 session，不需跨 agent 通訊 | 如果有 Cowork agent 跨系統需求再考慮 |
| Self-healing maintenance | OpenClaw 24h cycle | 目前沒有 index 需要 rebuild | 有 SQLite/向量 DB 時需要 |
| mem0 整合 | mem0 SDK | 未來向量記憶時再評估 | Phase 4 |

**CTO 原則：「Do not introduce vector search until the file-based system proves insufficient.」**
