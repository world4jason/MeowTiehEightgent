# Devlog 2026-03-27 — Rebirth Branch: Python-only + Kanban

## Context

v0.9.0 之後 main branch 走向全 JS（刪除 Python backend），但合併 paperclip 的嘗試最終失敗。決定從 v0.9.0 開出 `rebirth` branch，回歸 Python chat backend，清理 JS/Node.js 殘留。

## Changes

### 1. 專案瘦身：移除 JS/Cowork 系統
- 將 `ui/`、`server/`、`packages/`、`pnpm-workspace.yaml`、`tsconfig.*`、`Dockerfile.cowork` 等全部移至 `deprecated/`
- 根目錄只剩 Python chat 相關檔案
- 前端改用 `static/index.html`（vanilla JS）直接由 FastAPI serve

### 2. Scenario 選擇 UX 修正
- **修復 onclick 引號衝突 bug**：`JSON.stringify` 產生雙引號與 `onclick="..."` 衝突 → 改用 `onclick='...'` 單引號
- **加強 tab 選中視覺**：Workspace/Scenario/Blank tab 選中時改為綠底白字
- **加強卡片選中視覺**：選中的 scenario 卡片加綠色邊框 + 光暈 + 「已選定此情境」提示文字
- **解耦 scenario 與 agent**：選 scenario 不再自動勾選 suggested_agents
- **改 topic hint 為 placeholder**：不再自動填入 textbox，改為灰色提示

### 3. Settings 新增「情境」Tab
- 在 Settings 頁面新增「情境」tab（位於技能與工作區之間）
- 支援 CRUD：列表瀏覽、新增、編輯、刪除
- UI 結構仿照技能 tab 的 grid 卡片樣式
- 欄位：ID、名稱、描述、主題提示、系統提示詞

### 4. Mini Kanban 討論看板
- 對話頁面頂部新增 3 欄看板：TODO / In Progress / Done
- 進入對話時 topic 自動放入 In Progress
- 支援拖曳（drag & drop）移動項目狀態
- 支援在 TODO 欄位新增項目
- **後端整合**：kanban 狀態透過 WS `kanban_update` 即時同步
- **Agent 感知**：`build_prompt` 注入 `## Discussion Board`，每個 agent 回應前都能看到討論看板狀態

### 5. app.py 重構 — 2973 → 418 行
- 拆分為 `core/`（10 modules）+ `routes/`（11 modules）
- 遵循 FastAPI best practice：每個 route file 一個 `APIRouter()`
- 所有 re-exports 保留在 app.py，確保 237 個測試不受影響
- 移除 `DEFAULT_*_MD` 硬編碼，`agents/_default/` 為唯一 template source

### 6. Bug Fix — 踢人中斷 subprocess
- 踢掉正在回應的 agent 時，立即 cancel subprocess + 跳到下一個 speaker
- 修正前：subprocess 繼續跑完，回應照送

## Architecture Decisions

- 回歸 vanilla JS 前端（static/index.html）而非 React，保持簡單
- Kanban 狀態存在前端記憶體 + WS 即時同步，不另外持久化（session 內有效）
- Agent prompt 注入討論看板時，In Progress 項目排最前，引導 agent 聚焦
- `agents/_default/` 必須存在於 git，不設 fallback — 避免額外機制
