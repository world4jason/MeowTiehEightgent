核心洞察：global models 本質上是「adapter 連線預設」— 告訴系統怎麼連到 Claude/Gemini/Ollama。 Agent config 只說「我用 claude」，連線細節由 global 提供。

問題核心：兩層概念混在一起

Chat 的 "model"

混合了兩個東西：
① Adapter type（怎麼連：CLI subprocess? HTTP API?）
② Model variant（用哪個 model：sonnet? opus? llama3.2?）

例："claude" 和 "claude-opus" 是同一個 adapter（claude CLI），只是 model 不同。
但在 global models table 裡它們是兩筆獨立 entry。

Mth 的 "adapter"

乾淨分離：
① adapterType = "claude_local"（怎麼連）
② adapterConfig.model = "claude-sonnet-4-6"（用哪個 model）

同一個 adapter 可以跑不同 model。
不需要為每個 model variant 建一筆 entry。

解法：重構 Global Models → Adapter Presets

核心改動：拆分「怎麼連」和「用什麼 model」

// config.json — 改名 models → adapter_presets
{
  "adapter_presets": {
    "claude_local": {
      "command": "claude",
      "defaultArgs": ["--print"],
      "defaultModel": "claude-sonnet-4-6",
      "timeoutSec": 120,
      "startupTimeoutSec": 120,
      "supports_image": true
    },
    "gemini_local": {
      "command": "gemini",
      "defaultArgs": ["-p"],
      "defaultModel": "gemini-2.5-flash",
      "timeoutSec": 600,
      "startupTimeoutSec": 120,
      "supports_image": true
    },
    "ollama_api": {
      "baseUrl": "http://127.0.0.1:11434",
      "defaultModel": "llama3.2",
      "timeoutSec": 120
    }
  }
}

BEFORE: agents/claude/config.json

{
  "model": "claude",

  "supports_thinking": true,

AFTER: agents/claude/config.json

{
  "adapter": "claude_local",

  "adapterConfig": {
    "model": "claude-sonnet-4-6"
  },

  "model_tiers": {
    "default": "claude-sonnet-4-6",
    "thinking": "claude-opus-4-6"
  },

  "emoji": "🟣",
  "role": "engineer",
  "title": "Senior AI Developer"
}

解析流程（新）

get_agent_registry():
  1. 讀 agents/claude/config.json
     → adapter = "claude_local"

  2. 讀 config.json → adapter_presets["claude_local"]
     → command = "claude", defaultArgs = ["--print"], timeoutSec = 120

  3. Merge: preset + agent.adapterConfig
     → model = agent.adapterConfig.model ?? preset.defaultModel
     → timeout = agent.adapterConfig.timeoutSec ?? preset.timeoutSec
     → command = agent.adapterConfig.command ?? preset.command

  4. model_tiers 解析：
     → thinking model = "claude-opus-4-6"
     → 同一個 adapter，只換 model 參數
     → 不需要在 global table 另建一筆 "claude-opus" entry！

stream_cli_agent(agent):
  cmd = [command, ...defaultArgs, "--model", model, prompt]
  timeout = resolved timeout

這個改動解決了什麼

問題 Before After
Model variant 膨脹 claude, claude-opus, claude-haiku 各一筆 entry 一個 claude_local preset，model 是參數
model_tiers 查找 thinking model 必須在 global table 有 entry 同 adapter，只換 model 參數，不查 global
改 timeout 改 global → 所有 agent 變。無法 per-agent preset = default。agent.adapterConfig = override
跟 Mth 對齊 Chat 用 "model" soft ref，Mth 用 "adapterType" 都用 adapter type，語意一致
Settings Models Tab CRUD models entries 改成 CRUD adapter_presets（UI 調整小）
Ollama endpoints 讀 models.ollama.baseUrl 讀 adapter_presets.ollama_api.baseUrl ✅

Migration 步驟

  1. 寫 migration script：config.json.models → config.json.adapter_presets（重新歸類）
  2. 更新每個 agents/{name}/config.json：model: "claude" → adapter: "claude_local"
  3. 更新 app.py get_agent_registry()：新的 merge 邏輯
  4. 更新 stream_cli_agent()：從 merged config 拿 command + model
  5. 更新 Settings Models Tab → Adapter Presets Tab
  6. 更新 model_tiers 解析：不查 global，直接換 model 參數
