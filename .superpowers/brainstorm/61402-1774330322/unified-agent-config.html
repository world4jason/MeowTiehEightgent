Unified Agent Config — 合併方案

agents/{name}/config.json — 一個檔案，兩個世界都用

欄位對照 & 合併結果

統一欄位 Chat 來源 Mth 來源 說明
IDENTITY — 兩邊共用
role —（新增） role engineer, designer, pm, qa, ceo... Chat 可用來塑造對話人格
title —（新增） title 自由文字職稱，Chat UI 可顯示在名字下方
emoji emoji —（icon 改用 emoji） 視覺識別。Mth 原用 lucide icon name，統一改 emoji 更直覺
color color —（新增） Hex 色碼，Chat 氣泡/標記用，Cowork 也可用
description description capabilities 合併為一個欄位，描述 agent 能做什麼
enabled enabled status → bool Mth 的 active/paused/idle 簡化為 bool。runtime status 另外追蹤
MODEL / ADAPTER — 統一抽象
adapter model (soft ref) + type adapterType 統一用 Mth 的 adapter 概念：claude_local, gemini_local, ollama_api, ...
adapterConfig cmd, baseUrl, timeouts adapterConfig adapter 專屬設定。Chat 的 cmd/baseUrl/timeout 收進這裡
model_tiers model_tiers —（新增） { default, thinking, arbiter }。Mth 也能受益於 task-tiered model
SKILLS — 統一
skills skills[] runtimeConfig.desiredSkills 統一為 top-level skills[]，soft ref 到 skills/{slug}/
COWORK 擴充 — Mth 專用但 file-based
reportsTo — reportsTo Agent 階層。Chat 暫不用，但留著不礙事
permissions — permissions { canCreateAgents, ... }。Cowork 用，Chat 可忽略
budget — budgetMonthlyCents 月預算（cents）。Chat 端看 token 統計也能受益
heartbeat — runtimeConfig.heartbeat cooldown、interval、wake triggers。Cowork job scheduler 用

被刪掉/移走的欄位

舊欄位 去向 原因
Chat: model (soft ref) → adapter + adapterConfig.model 不再需要 config.json 裡的全局 models 表。adapter 自帶 model info
Chat: type (cli|api) → adapter 隱含 claude_local = CLI, ollama_api = API。adapter name 自帶 type
Chat: supports_thinking → adapter 自知 or model_tiers 存在即支持 有 model_tiers.thinking = 支持 thinking
Chat: mode (chat|think) → runtime state（不存 config） session 級別的狀態，不應該寫死在 agent config
Mth: icon (lucide name) → emoji 取代 emoji 更直覺、更 universal、不依賴 icon library
Mth: status → enabled + runtime state config 只管 enabled/disabled。running/idle/error 是 runtime state
Mth: capabilities → description 合併 兩個自由文字欄位沒必要分開
Mth: metadata → 保留但不放 config.json runtime metadata 由 Mth DB 自行管理

File Structure（不變）

agents/{name}/
├── config.json          ← 統一規格（上面這個）
├── AGENT.md             ← 指令（Chat 用，Mth 的 instructionsFilePath 指向這裡）
├── IDENTITY.md          ← 人格
├── SOUL.md              ← 驅動力
├── MEMORY.md            ← 長期記憶
└── memory/
    └── YYYY-MM-DD.md    ← 每日記憶
