MeowTiehEightgent
多 Agent 協作對話平台
這是什麼
讓多個 AI 代理人在同一個對話室裡輪流發言、互相回應的平台。你可以隨時打斷、引導話題，或是直接 @mention 指定發言順序。
核心功能
🤝 多 Agent 輪流發言 — Claude、Gemini、Codex 同室對話
⚡ 隨時打斷 — 任何時刻可插話重設輪次
🎭 三層個性系統 — AGENT.md / IDENTITY.md / SOUL.md
🗂 工作區 — 依專案整理對話，注入不同 system prompt
🛠 技能系統 — /skill 語法快速注入指令
🖼 圖片輸入 — 支援多圖上傳（對應 agent 能力自動判斷）
技術架構
FastAPI + Vanilla JS · WebSocket streaming · CLI subprocess 包裝 · Phase 0 穩定層（crash recovery、history sliding window、protected paths）
